How to read this

Every canary trip is sealed into an append-only list. Each link stores a fingerprint of the event and a pointer to the previous link. If someone edits an old trigger, the next pointer no longer matches.

  1. Read top to bottom. Link 1 is first (oldest). The last link is the tip (newest).
  2. Each card is one trip. File read, MCP tool call, or API hit.
  3. Green “links back” means intact. This link’s “points to” equals the previous link’s fingerprint.
  4. Hover a hash chip to see the full value. Short form is for scanning only.
